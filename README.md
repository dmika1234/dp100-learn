# 🎓 Preparation Guide - Azure Data Scientist Associate (DP-100)

This repository provides practical materials to help you prepare for the [**Microsoft Certified: Azure Data Scientist Associate (DP-100)**](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/?practice-assessment-type=certification) exam.  
It focuses on applying core concepts using **Azure Machine Learning** and **Azure AI Foundry**, following a hands-on, task-oriented approach.

The guide is centered on the **core topics required for the DP-100 exam**, summarizing and extending the  
[official Microsoft learning path](https://learn.microsoft.com/en-us/training/courses/dp-100t01).  
Some sections reference the official tutorials directly, while others expand on areas that are less detailed in Microsoft’s materials — to provide a more complete, practice-oriented understanding.

The goal is to make it easier to understand how different Azure ML components fit together — from data preparation and experiment tracking to model deployment and monitoring — using the **Azure ML Python SDK v2** and related Azure AI services.

> **Note:** Some materials may become outdated as Azure Machine Learning and AI Foundry are frequently updated. ![Last Update](https://img.shields.io/github/last-commit/dmika1234/dp100-learn/main?label=Last%20Update)
