# 🎓 Preparation Guide - Azure Data Scientist Associate (DP-100)

This repository provides practical materials to help you prepare for the [**Microsoft Certified: Azure Data Scientist Associate (DP-100)**](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/?practice-assessment-type=certification) exam.  
It focuses on applying core concepts using **Azure Machine Learning** and **Azure AI Foundry**, following a hands-on, task-oriented approach.

The guide is centered on the **core topics required for the DP-100 exam**, summarizing and extending the  
[official Microsoft learning path](https://learn.microsoft.com/en-us/training/courses/dp-100t01).  
Some sections reference the official tutorials directly, while others expand on areas that are less detailed in Microsoft’s materials — to provide a more complete, practice-oriented understanding.

The goal is to make it easier to understand how different Azure ML components fit together — from data preparation and experiment tracking to model deployment and monitoring — using the **Azure ML Python SDK v2** and related Azure AI services.

## 🧭 Guide

### 🎯 Is This Certification Right for You?

The **Azure Data Scientist Associate (DP-100)** certification validates your ability to use **Azure Machine Learning** to build, train, and deploy machine learning models and use **Azure AI Foundry** services to develop generative AI solutions.

It’s best suited for data professionals who:

* Have experience with **data science** or **machine learning** concepts.
* Want to strengthen their practical skills in **Azure Machine Learning** and **Azure AI Foundry**.
* Aim to enhance their **career profile** with an Azure certification.

If you’re new to cloud or data science, consider starting with **AZ-900** or a more foundational course.
However, if you already have some experience and are ready to learn by doing, this guide will help you prepare efficiently.

---

### 🧠 Learning Prerequisites

To follow this guide effectively, you should have:

* A basic understanding of **data science** and **machine learning**.
* Familiarity with **Python programming**.
* Some knowledge of **cloud computing** (helpful but not required).
* Access to an **Azure subscription** for hands-on practice.

Available options:

* **[Free Azure Account](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account)** — includes **$200 credit for 30 days** and limited free-tier services for 12 months.
* **[Azure for Students](https://azure.microsoft.com/en-us/free/students/)** — provides **$100 credit** and 12 months of free core services (**no credit card required**).
* Access via your **organization or university** (if available).

---

### 🧩 How to Learn Effectively

Azure evolves rapidly, and so does the **DP-100 exam**. Before you start, always review the
[**official exam skills outline**](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-100)
to focus on the most up-to-date content.

You can follow the official
[**Microsoft Learn course**](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/?source=recommendations&practice-assessment-type=certification)
as your main study path.
However, not all topics in the exam outline are covered there. This repository complements the Microsoft materials with additional explanations, practical examples, and hands-on exercises.

### 🧾 Learning Outline

#### 1. Create a Learning Plan

1. Review the [official exam outline](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-100) to identify key topics.
2. Define a **study timeline** that fits your schedule.
3. Break down topics into smaller sections for consistent progress.
4. Compare the official **Microsoft Learn course** with the outline to identify knowledge gaps.

#### 2. Prepare Your Environment

1. Obtain an **Azure subscription** (free options available).
2. [Set up your local or cloud-based environment](./notes/Azure%20-%20Setting%20Up.md).
3. [Create your first Azure ML workspace and configure the Python SDK v2](./notes/Azure%20ML%20-%20First%20Steps%20with%20Python%20SDK%20v2.md).

Use these notes and tutorials to **extend and reinforce** your learning:
