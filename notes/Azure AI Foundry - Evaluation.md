# Azure AI Foundry - Evaluation

## Importance of Evaluation

- **Quality Assurance**: Ensures the app provides accurate and relevant responses, leading to improved user satisfaction.
- **Continuous Improvement**: Evaluation results help identify areas for enhancement, allowing iterative improvements to the app.
- **User Experience**: High-quality, helpful responses increase the likelihood of continued app usage.

---

## Assessing Model Performance

### Evaluation Phases

- **Individual Model Evaluation**: Analyze input, output, and optionally compare to expected output.
- **Chat Flow Evaluation**: Assess the orchestration of multiple models and code in a flow, evaluating both the complete flow and individual components.

---

## Evaluation Approaches

### 1. Model Benchmarks

- **Accuracy**: Checks if generated text matches the correct answer exactly.
- **Coherence**: Measures if output flows smoothly and resembles human language.
- **Fluency**: Assesses grammatical correctness and natural-sounding responses.
- **GPT Similarity**: Quantifies semantic similarity between ground truth and model prediction.

*Benchmarks are available in the Microsoft Foundry portal for all models before deployment.*

---

### 2. Manual Evaluations

- **Human Raters**: Assess quality based on relevance, informativeness, and engagement.
- **Insights**: Capture aspects automated metrics may miss (e.g., context relevance, user satisfaction).

---

### 3. AI-Assisted Metrics

- **Generation Quality Metrics**: Evaluate creativity, coherence, and adherence to style/tone.
- **Risk and Safety Metrics**: Assess for harmful or biased content.

---

### 4. Natural Language Processing (NLP) Metrics

- **F1-score**: Ratio of shared words between generated and ground truth answers.
- **BLEU**: Bilingual Evaluation Understudy metric.
- **METEOR**: Metric for Evaluation of Translation with Explicit Ordering.
- **ROUGE**: Recall-Oriented Understudy for Gisting Evaluation.

*All measure overlap between model output and expected response.*

---

## Manual Evaluation Process

### 1. Prepare Test Prompts

- Create a diverse set of prompts covering common queries, edge cases, and failure points.

### 2. Test in Chat Playground

- Use the chat playground in Microsoft Foundry to interact with the model.
- Enter prompts, review responses, and tweak prompts/system messages as needed.

### 3. Evaluate Multiple Prompts

- Use the **manual evaluations** feature to upload a dataset of questions (and expected responses).
- Rate responses (thumbs up/down) to quickly assess performance across a dataset.
- Use results to improve prompts, system messages, model selection, or parameters.

---

## Automated Evaluations

### 1. Evaluation Data

- Use a dataset of prompts and responses (optionally with ground truth).
- Datasets can be manually compiled or generated by AI models and edited as needed.

### 2. Evaluation Metrics

- **AI Quality**: Use evaluators for coherence, relevance, and standard NLP metrics (F1, BLEU, METEOR, ROUGE).
- **Risk and Safety**: Evaluators check for content safety issues (violence, hate, sexual content, self-harm).

*Automated evaluations in Microsoft Foundry allow assessment of models, datasets, or prompt flows for both quality and safety.*

**Key Takeaway:**  
Use a combination of manual and automated evaluations, leveraging both human insight and quantitative metrics, to ensure your generative AI app is accurate, safe, and continuously improving.
